# Modz

Mods for [Cheese Rolling](https://store.steampowered.com/app/3809440/) on Steam. Install them with **[Modzarella](https://github.com/ModzarellaHQ/Modzarella)**.

Mods run in **Play Offline** only. Press **F1** in game for the mod menu.

| Mod | What it does | Keys |
|---|---|---|
| `core` | Required. Mod menu, mouse camera, first person, zoom, speed FOV | F1 menu · F3 camera · V first person · scroll zoom |
| `bmw` | Drivable BMW M2: crash damage, headlights, engine sounds | E enter/exit · WASD · Space brake · Shift nitro · H horn · R flip · Backspace reset |
| `gore` | Limbs come off, bleeding out, wounds, car and bullet gore | – |
| `guns` | Glock 17 and AK-47: recoil, aim, reloads | 1 / 2 draw · 3 holster · LMB fire · RMB aim · R reload |
| `toilet` | Rocket toilet flown on a column of poop | T sit · Space thrust · Ctrl hover · WASD steer |
| `euphoria` | Active ragdolls: brace, shield, flinch, writhe | – |
| `tweaks` | Endless round, freeze bots, slow motion, VSync/FPS cap | F2 endless · F4 freeze · F5 slow motion |

## Layout

```
mods/<id>/
  mod.json       id, name, version, author, description, dependencies, credits
  <Name>.csproj  <Project Sdk="Microsoft.NET.Sdk" />
  *.cs           source
  files/         exactly what gets installed: the built DLL plus any assets
```

`index.json` is generated by GitHub Actions from `mods/*/mod.json` and `files/`, and published with the files on GitHub Pages. Don't commit it.

## Add or change a mod

1. Install the game, [BepInEx 5.4.23.5](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5) (Modzarella does this) and the .NET SDK 8+.
2. Copy an existing mod folder, or start from:

   ```json
   { "id": "mymod", "name": "My Mod", "version": "1.0.0", "author": "you",
     "description": "One line.", "dependencies": ["core"], "credits": ["Model by X, CC-BY 4.0, link"] }
   ```

   ```csharp
   [BepInPlugin("modz.mymod", "My Mod", "1.0.0")]
   [BepInDependency(CorePlugin.GUID)]
   public class MyModPlugin : BaseUnityPlugin
   {
       void Awake()
       {
           Config.Bind("General", "Enabled", true, "Shown in the mod menu.");
           Config.Bind("My Mod", "Power", 1f, ModCommon.Desc("Slider in the menu.", new AcceptableValueRange<float>(0f, 5f)));
           MenuRegistry.Action("modz.mymod", "Do it", () => ModCommon.Toast("Done"));
       }
   }
   ```

3. Build: `dotnet build mods/mymod -c Release`. The DLL lands in `mods/mymod/files/`. Set `GameDir="/path/to/Cheese Rolling"` if the game isn't in the default Steam folder.
4. Test: copy `files/` to `BepInEx/plugins/Modz/mymod/`, or point Modzarella's mod source (Settings) at your clone after running `python3 .github/index.py`.
5. Bump `version` in `mod.json`, commit the source and `files/`, and open a pull request. CI checks every `mod.json`.

Every `Config.Bind` shows up in the F1 menu. Useful Core APIs:

| API | Use |
|---|---|
| `ModCommon.Active`, `InRound`, `LocalRagdoll()`, `AllRagdolls()`, `BodyScale(r)` | Game state |
| `ModCommon.KeyDown`, `Key`, `Toast`, `MenuRegistry.Action`, `QuickToggle` | Input, menu, messages |
| `CheeseApi.IsSeated`, `SetSeated`, `Driver`, `IsVehicle`, `HandsBusy` | Vehicles, seats, held items |
| `CheeseApi.BulletHit`, `IsDead`, `FirstPerson`, `MenuOpen` | Hooks between mods |
| `KinematicSeat`, `GlbLoader.Load`, `Wav.LoadFolder`, `ModCommon.Solid` | Seats, .glb models, .wav sounds, materials |

## Rules

- Offline only: check `ModCommon.Active` first.
- No game files, decompiled code or ripped assets.
- Credit every third-party asset and its license in `credits`.
