# Modz

Lua mods for [Cheese Rolling](https://store.steampowered.com/app/3809440/), installed with [Modzarella](https://github.com/ModzarellaHQ/Modzarella).

## Adding a mod

Add a folder to `mods/` with `mod.json`, `main.lua` and assets in `files/`, following the rules in [CONTRIBUTING.md](CONTRIBUTING.md). The [Lua API](https://github.com/ModzarellaHQ/Modzarella/blob/main/docs/lua-api.md) covers the code.

Test with `python3 .github/index.py` and `Modzarella source .`, then open a pull request. Code is MIT.
